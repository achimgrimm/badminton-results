# Aufstellung für alle Spieler

Der Mannschaftsführer kann die geplante Aufstellung jetzt **veröffentlichen**. Du siehst sie in der **Vorschau** unter „Aufstellung vom Mannschaftsführer“ – nur lesen, ändern kann sie nur der Mannschaftsführer.

- **Erst planen, dann veröffentlichen**: Der Entwurf bleibt privat, bis „Veröffentlichen“ gedrückt wird. Mit „Zurückziehen“ verschwindet sie wieder.
- **Dein Name fällt auf**: Bist Du als Spieler gewählt, steht Dein Name fett.
- **Auch offline**: Die zuletzt geladene Aufstellung bleibt sichtbar.

Dafür musst Du angemeldet sein.
